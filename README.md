# Análise Estocástica: Coleção de Figurinhas

Este projeto tem como objetivo realizar uma análise estatística e uma simulação computacional sobre o esforço necessário para completar um álbum de figurinhas.

## Objetivos
- Calcular o esforço teórico utilizando distribuições probabilísticas (Poisson e Binomial Negativa).
- Modelar o comportamento real através de uma Simulação de Monte Carlo.
- Comparar a teoria (Probabilidade Constante) com a prática (Problema do Colecionador de Cupons).

## Tecnologias Utilizadas
- Python
- NumPy (Cálculos numéricos)
- Matplotlib (Visualização de dados)
- SciPy (Distribuições estatísticas)

## Como utilizar
1. Clone este repositório.
2. Abra o arquivo `analise_estocastica_album.ipynb` no Jupyter Notebook ou Google Colab.
3. Execute as células sequencialmente.

## Resultados
Os gráficos gerados demonstram a diferença entre o modelo teórico e o modelo estocástico, evidenciando como a dificuldade de completar o álbum aumenta conforme nos aproximamos da completude.
